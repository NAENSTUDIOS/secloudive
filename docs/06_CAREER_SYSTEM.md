# Career System

The Career Hub provides Resume Builder, LinkedIn Builder, Portfolio Builder, ATS Optimization, Mock Interviews, Career Roadmaps, Internship Tracker, Job Tracker, and Certification Tracker.

Completed learning, labs, projects, simulations, investigations, reviews, and certificates produce reusable portfolio evidence. Evidence includes skills, role mapping, rubric results, artifacts, timestamps, and verification IDs.

Recruiter mode presents public portfolios, projects, labs, architecture reviews, investigations, threat hunts, certificates, skill scores, readiness, and evidence packages without exposing private learner data.
