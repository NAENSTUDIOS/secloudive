# Learning Architecture

## Unit hierarchy

`Track -> Path -> Module -> Room -> Activity -> Evidence`

Every module must connect prerequisite concepts, reading, slides, checks, labs, projects, documentation, interview questions, portfolio evidence, and related roles.

## Content levels

Each topic provides Beginner, Intermediate, Advanced, Expert, Architecture, Security, Best Practices, Troubleshooting, and Production guidance.

Each module provides Overview, Visual, Architecture, Deep Dive, Summary, Revision, Interview, and Certification slides.

## Progression

`Beginner -> Intermediate -> Advanced -> Job Ready`

Completion unlocks the next room. Progress records completed modules and activities, assessment results, time spent, skill scores, notes, and evidence references.

## Foundation standard

All roles begin with Computer Fundamentals, Operating Systems, Linux, Networking, Git, Python, Cloud Fundamentals, Security Fundamentals, AWS basics, documentation, and communication. Foundations must teach: Understand, Visualize, Observe, Practice, Simulate, Apply, Troubleshoot, Explain, Teach, Perform.
