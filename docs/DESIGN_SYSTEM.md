# SeCloudive Design System

## Direction

Premium, calm, technical, trustworthy, and focused. Avoid neon overload, gaming-dashboard clutter, excessive gradients, heavy shadows, decorative fonts, and motion that competes with learning.

## Tokens

Use CSS tokens rather than hardcoded values:

- Primary cloud blue: `#2563EB`
- Deep navy: `#0F172A`
- Security cyan: `#06B6D4`
- Success: `#10B981`
- Warning: `#F59E0B`
- Danger: `#EF4444`
- Dark surface: `#0B1220`
- Dark elevated: `#111827`
- Dark border: `#1F2937`

Use a neutral 50-900 scale, Inter/system UI typography, an 8px spacing grid, radius tokens 8/12/16/24px, and subtle xs/sm/md/lg shadows.

## Components

Button, Card, Modal, Drawer, Tooltip, Dropdown, Tabs, Accordion, Badge, Input, Search, Table, Command Palette, Breadcrumb, Progress Bar, Activity Card, Learning Card, Lab Card, Career Card, and Achievement Card.

All components support dark/light themes, keyboard access, screen readers, visible focus, reduced motion, and consistent icon sizing through Lucide.

## Templates

- Landing: hero, problem, solution, pathways, proof, CTA.
- Catalog: header, search, filters, grid, pagination.
- Learning: overview, objectives, modules, progress, recommendations.
- Lab: objectives, instructions, workspace, hints, validation.
- Career: roadmap, gap analysis, portfolio, recommendations.
- Account: progress, achievements, reports, settings.

## Quality gate

Every screen must make its purpose, next action, status, and recovery path obvious within 10 seconds. Avoid horizontal scrolling on mobile. The next action should be visible within five seconds on dashboards.
