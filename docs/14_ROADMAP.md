# SeCloudive Roadmap

## Phase 1 — Foundation

Landing page, authentication, user dashboard, learning dashboard, admin dashboard, course system, and resource library.

## Phase 2 — Learning

Unified paths, modules, rooms, reading materials, slides, notes, assessments, progression, and official resources. The resource intelligence contract is defined in [RESOURCE_INTELLIGENCE_SYSTEM.md](./RESOURCE_INTELLIGENCE_SYSTEM.md).

## Phase 3 — Practice and experience

Unified Practice catalog, guided/practical/challenge/production/troubleshooting labs, projects, tickets, incidents, roleplay, and day-in-the-life simulations. The safe job simulation contract is defined in [REAL_JOB_SIMULATION_OS.md](./REAL_JOB_SIMULATION_OS.md).

## Phase 4 — Career

Portfolio, resume, LinkedIn, ATS, interviews, certifications, internships, jobs, recruiter verification, and performance rubrics.

## Phase 5 — Intelligence and operations

AI mentor, citation engine, hint system, notes organizer, admin command deck, analytics, CMS, monitoring, and community.

## Priority order

P0: remove provider keys from the frontend, secure AI proxy, Supabase RLS, server-verified admin authentication.  
P1: public catalog browsing, unified Learn, unified Practice, connected progression.  
P2: AI mentor, notes, analytics, certification domain mapping.  
P3: production deployment, CI/CD, monitoring, and scale.

## Traceability gate

Every phase must maintain [MASTER_TRACEABILITY_MATRIX.md](./MASTER_TRACEABILITY_MATRIX.md). A feature cannot advance to staging or production while its owner, status, tests, events, analytics, security review, documentation, or rollback evidence is missing.
