# UI/UX Guidelines

SeCloudive should combine the clarity of Apple, Stripe, Notion, GitHub, and Linear with its own security-operations identity.

Requirements:

- Modern, minimal, fast, professional, responsive, mobile-first.
- Dark and light themes with readable contrast.
- WCAG-conscious semantic HTML, labels, focus states, keyboard navigation, screen-reader support, and reduced motion.
- Clear Home, Learn, Practice, Career, and Account navigation.
- Consistent buttons, inputs, cards, tables, dashboards, modals, navigation, charts, and feedback states.
- Fast initial load through route splitting, stable layouts, and meaningful loading states.

Every screen must answer: where am I, what can I do, what happens next, and how do I recover?
