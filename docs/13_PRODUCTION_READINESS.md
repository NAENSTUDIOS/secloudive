# Production Readiness

## Targets

Performance 95+, accessibility 100, SEO 95+, and best-practices 100 where measured by the chosen tooling.

## Checklist

- Documentation, tests, security review, scalability, backups, migrations, observability, alerting, and incident runbooks.
- Prometheus/Grafana-compatible metrics, structured logs, API monitoring, error monitoring, availability checks, and tracing.
- Recovery objectives, data retention, dependency ownership, release notes, rollback plan, and support contact.
- Production smoke tests for authentication, learning progress, labs, career evidence, and admin authorization.
