# Certification System

Certification objectives map to:

`Objective -> Module -> Lab -> Investigation -> Project -> Interview -> Job Task -> Portfolio Evidence`

Coverage includes AWS CCP, SAA, DVA, SOA, Security Specialty, and SAP; Azure AZ-900, AZ-104, AZ-305, and AZ-500; Kubernetes CKA, CKAD, and CKS; Terraform Associate; and Security+, CySA+, and CISSP.

The hub tracks objectives, readiness, practice scores, weak domains, exam notes, target dates, and completed evidence. Certification readiness must measure practical performance rather than quiz score alone.
