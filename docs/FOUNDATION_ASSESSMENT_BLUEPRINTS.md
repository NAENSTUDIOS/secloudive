# Foundation Assessment Blueprints

**Owner:** `OWNER-LEARN-001`  
**Status:** `PLANNED`  
**Priority:** Critical

## Resource admission scoring

Every candidate foundation resource receives a 0-100 score:

```text
authority 30% + accuracy 20% + practical_value 15% +
beginner_friendliness 10% + visual_quality 10% +
career_relevance 10% + recency 5%
```

Admission policy:

| Score | Classification | Policy |
|---:|---|---|
| 95-100 | Elite | Default foundation recommendation |
| 90-94 | Excellent | Approved primary or secondary resource |
| 80-89 | Very good | Approved supplementary resource |
| 70-79 | Supplementary only | Never the sole source for a core objective |
| Below 70 | Not allowed | Reject or archive |

Scores require reviewer evidence. Authority alone cannot compensate for inaccurate or unsafe material.

## Foundation lesson minimum

Every lesson requires official documentation, visual diagrams, beginner explanation, interactive simulation, guided lab, independent lab, troubleshooting exercise, real job example, threat example, interview questions, and a knowledge check.

## Assessment weighting

| Area | Weight |
|---|---:|
| Knowledge | 30% |
| Practical performance | 40% |
| Communication | 10% |
| Documentation | 10% |
| Troubleshooting | 10% |

Minimum passing score is 80%. A critical security or safety failure requires remediation regardless of total score.

## Assessment package

Each foundation topic includes:

- 20 multiple-choice questions
- 5 visual questions
- 2 mini labs
- 1 documentation task
- 1 troubleshooting scenario
- 1 role simulation
- 1 practical review

## Linux blueprint

Knowledge areas: filesystem 20%, permissions 20%, processes 15%, networking 15%, services 10%, logs 10%, troubleshooting 10%.

Practical exam:

1. Fix a permission issue.
2. Restart a failed service.
3. Analyze logs.
4. Create a secure user.
5. Document findings.

Role simulation: Junior Cloud Engineer.

## Networking blueprint

Knowledge areas: OSI 10%, TCP/IP 15%, DNS 15%, routing 20%, CIDR 20%, firewalls 10%, troubleshooting 10%.

Practical labs: subnet design, routing analysis, DNS investigation, traffic-flow troubleshooting, and network security review.

Role simulations: Network Engineer and Cloud Engineer.

## Git and GitHub blueprint

Knowledge areas: commits 20%, branches 20%, pull requests 15%, collaboration 15%, repositories 15%, workflows 15%.

Practical exam: create a repository, create a branch, open a pull request, resolve a conflict, merge code, and document the workflow.

## Python blueprint

Knowledge areas: variables 10%, functions 20%, files 15%, JSON 15%, automation 20%, APIs 10%, troubleshooting 10%.

Practical tasks: create a cloud automation script, parse logs, call an API, generate a report, and document the solution.

Role mappings: Cloud Engineer, Cloud Security Engineer, DevSecOps Engineer.

## Cybersecurity blueprint

Knowledge areas: CIA triad 10%, authentication 15%, authorization 10%, encryption 15%, hashing 10%, threats 15%, incident response 15%, risk management 10%.

Practical tasks: analyze an incident, classify a threat, recommend controls, document findings, and present a report.

## Cloud blueprint

Knowledge areas: compute 15%, storage 15%, networking 20%, IAM 20%, monitoring 10%, security 10%, cost optimization 10%.

Practical assessment: build an architecture, deploy in simulation, secure the environment, create monitoring, estimate cost, and generate documentation.

Role simulations: Junior Cloud Engineer and Cloud Support Associate.

## Foundation capstone

Before entering an advanced role pathway, learners complete Linux, networking, Git, Python automation, cloud architecture, security review, monitoring setup, incident investigation, and documentation projects.

Deliverables: architecture diagram, Git repository, technical documentation, lab reports, security review, and incident report.
