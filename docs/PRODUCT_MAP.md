# SeCloudive Product Map

This is the canonical short index for the product surface. The detailed,
evidence-based matrix is maintained in
[PRODUCT_MASTER_MAP.md](./PRODUCT_MASTER_MAP.md).

## Current product

- Learn: paths, quizzes, challenges, investigations, labs, skill tracking.
- Build: safe labs, projects, IaC templates, playbooks, audit exports.
- Earn: XP, streaks, badges, certificates, reports, portfolio evidence.
- Career: roadmaps, role gaps, interview simulator, internships, resume tools.
- AI: Sentinel/mentor chat, recommendations, architecture and interview review.
- Collaborate: public/custom labs and leaderboards.
- Cloud: AWS-focused simulations and multi-cloud learning crosswalks.

## Product truth

The current product is strongest as an offline-capable, investigation-first
cloud security learning platform. Real provider provisioning, enterprise
tenancy, full community collaboration, durable analytics, and production AI
governance are not yet complete.

## Canonical next sequence

1. Secure identity, admin, API, and CORS boundaries.
2. Make persistence and schema versioning reliable.
3. Close frontend/backend endpoint drift.
4. Formalize learning assessment and certification rules.
5. Add enterprise/community capabilities only on server-authoritative data.
