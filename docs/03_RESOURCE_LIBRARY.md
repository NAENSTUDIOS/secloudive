# Resource Library

## Source hierarchy

1. Official documentation and official learning platforms.
2. Standards, books, and vendor certification material.
3. High-quality industry courses.
4. Community projects and engineering blogs.

## Preferred sources

- AWS Documentation and Skill Builder
- Microsoft Learn
- Google Cloud Documentation and Skills Boost
- Kubernetes Documentation
- Docker Documentation
- HashiCorp Learn
- GitHub Skills
- Linux Foundation
- OWASP and MITRE ATT&CK
- OpenAI, Anthropic, and Microsoft AI documentation

Industry and community sources include KodeKloud, A Cloud Guru, Coursera, Pluralsight, Udemy, LinkedIn Learning, roadmap.sh, GitHub repositories, and open-source projects.

## Quality requirements

Every link must have provider, topic, level, format, canonical URL, last verification date, license/access note, and learning outcome. Prefer stable official URLs and label third-party resources clearly. Broken links must be reportable and removable by admins.
