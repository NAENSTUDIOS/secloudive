# Roleplay and Job Simulation System

## Core loop

`Company -> Manager -> Standup -> Ticket -> Issue -> Investigation -> Fix -> Documentation -> Review -> Postmortem`

Learners should feel like employees, not viewers.

## Roles

Cloud Engineer, Cloud Security Engineer, DevOps Engineer, DevSecOps Engineer, SOC Analyst, Security Analyst, SRE, Platform Engineer, Linux Administrator, AI Engineer, Cloud Architect, Solutions Architect, Security Architect, Consultant, and Principal Architect.

Each role defines daily, weekly, and monthly responsibilities; tools; tickets; incidents; meetings; deliverables; certifications; learning resources; projects; architecture reviews; performance measurements; and promotion requirements.

## Simulation modes

Day-in-the-Life, ticket queue, incident response, architecture review, manager review, presentation, and postmortem. Scenarios include outages, IAM errors, suspicious logins, failed pipelines, latency, DNS, databases, load balancers, and AI service failures.
