# AI Mentor System

Mentors: AWS, Azure, DevOps, Security, Linux, Networking, AI, and Career.

Capabilities:

- Explain concepts at the learner's level.
- Build adaptive roadmaps and study plans.
- Review code, projects, architecture, and documentation.
- Conduct technical, behavioral, architecture, manager, and panel interviews.
- Recommend verified resources.
- Provide progressive hints: Hint 1, Hint 2, Hint 3, then solution.

The mentor receives room, module, path, role, lab task, progress, and safety context. Responses should cite authoritative sources when applicable. AI requests must use authenticated server-side proxying, rate limits, filtering, logging, key rotation, and refusal guardrails. Provider keys never ship to the browser.
